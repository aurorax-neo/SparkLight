# 今日发送状态刷新修复

## 原因与处理

- 旧 `is_sparked_today` 无检测日期，跨日仍被前端直接显示为今日已发。新增独立 `today_checked_at`，按北京时间当天且非未来时间判断有效；不从 `updated_at` 或迁移时间补猜日期。
- 消息历史失败时，原 `None` 代表不更新，导致保留旧成功。显式失效历史检测，区分已发、未发和未确认。
- 同步仅处理匹配到好友列表的目标，遗漏部分已有会话。资料匹配与已有目标消息检测解耦；接口返回确认／未确认数量。
- 页面主刷新与行刷新开始时清除本地检测，异常后重读列表，部分失败不再显示全部同步成功；页面定时重算日期，过期状态不再跨日沿用。
- 系统成功发送时间在同步与调度器共用判断，排除未来时间；失败发送不抹除已有的有效消息证据。
- 群聊历史查询使用 cmd610 返回的真实短 ID，不以逻辑会话 ID 代替；检测未知仍停止发送。
- 客户端创建／更新请求不能直接认定今日已发。火花徽标不换行，保留表格内部横向滚动，并提供每页 20 条分页。
